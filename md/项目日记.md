模型仍然否认？
1. 工作记忆中的冲突内容仍然存在
即使你把长期记忆放在对话历史前面，工作记忆里最近几轮的对话历史仍然包含了多轮“我的密码编号是多少”以及 NPC 连续否认的回答。
大模型在生成时，会参考整个上下文，特别是最近的对话内容。系统级的指令有时压不过对话历史中反复出现的自洽性错误。
2. 角色设定中的“职业范围”与“保密”可能被过度解读
NPC 是物资管理员，你之前的回答里多次说“密码编号不在我管范围内”“属于机密信息”。
这种角色认知可能让模型在生成时更倾向于维持“不知道”的人设，即使检索到了玩家主动告知的记忆。
                ⬇️
把长期记忆放进 user 消息里。模型通常会更重视用户直接输入的内容，而不是系统提示。将可靠记忆伪装成玩家提供的“证据”，模型更愿意遵循。

---
FastAPI 是一个用于构建 Web API 的现代 Python 框架。其核心功能特性如下：

1. 高性能
基于 Starlette（网络部分）和 Pydantic（数据部分），底层使用异步 I/O（async/await）机制。在高并发场景下性能表现优异，可媲美 Node.js 与 Go 语言编写的框架。

2. 数据校验与序列化
深度集成 Pydantic。它利用 Python 类型提示（Type Hints）自动对请求体（JSON）、查询参数、路径参数进行数据类型校验和格式验证。同时，它能自动将 Pydantic 模型对象序列化为 JSON 响应体，确保接口输入输出的数据结构严格符合预期。

3. 自动生成交互式 API 文档
基于 OpenAPI 规范（OAS）自动生成文档。启动服务后，框架会自动提供两套可视化文档界面：Swagger UI（/docs）和 ReDoc（/redoc），方便开发人员在线调试和查看接口定义。

4. 依赖注入系统
内置简单的依赖注入功能（Depends）。可以复用认证逻辑、数据库会话管理、业务校验等通用代码，系统会自动解析依赖关系并在路由处理函数执行前完成注入。

5. 原生异步支持
全面支持 Python 的 async 和 await 语法，允许在视图函数中执行非阻塞的异步操作（如异步数据库查询、HTTP 请求调用），从而提升资源利用率和响应速度。

6. 安全性支持
内置多种常见的身份认证和授权机制，包括 OAuth2（密码流）、JSON Web Token（JWT）、API Key 等，简化安全接入层的开发工作。
